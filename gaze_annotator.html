    Tip: set up for Pupil sync

    This looks like a browser other than Google Chrome. The Pupil sync extension only runs in Chrome, so open this file in Chrome to use it.

    1. Use Google Chrome.
    2. Install the Pupil sync extension (once per computer)
      1. Type chrome://extensions in Chrome's address bar and switch on Developer mode (top right).
      2. Click Load unpacked and choose the pupil-sync-extension folder from the package (keep that folder where it is afterwards).
      3. On the extension's card click Details and switch on Allow access to file URLs.
      4. Click the puzzle-piece icon next to the address bar and pin the extension, so its button stays visible.
      5. Reload this page: a Sync Pupil box appears at the bottom. Tick it.
    3. Turn sync on for the Pupil tab: open the Manual Mapper, click the extension's button and switch Sync this tab on. A green ON badge shows it is on. The extension can reach only that tab, and only after you switch it on. Switch it off the same way. Reloading or closing the tab also turns it off.
    4. Put Pupil Cloud and this app side by side: right-click the Pupil Cloud tab, choose the split view option (for example Add tab to new split view), then pick this app's tab. You see the video and the tags together, and Pupil follows the gaze you are coding.
    5. Code with Space: on a gaze, press Space to play the gazes ahead in Pupil. Press Space again when the look changes: the gazes before it are selected as one chunk, ready for one tag.
    6. Click on this app's side before using the keys (A, D, B, U, Space): keys go to whichever side you clicked last.

    No split view option in your Chrome? Update Chrome, or drag the Pupil Cloud tab out into its own window and snap the two windows to the left and right halves of the screen.
